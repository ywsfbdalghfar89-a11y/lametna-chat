لمّتنا FINAL
نسخة مجمعة من المشروع مع:
- تسجيل وإنشاء حسابات
- غرف متعددة
- شات لحظي
- رسائل خاصة
- رتب وصلاحيات
- لوحة إدارة
- حظر وطرد
- إنشاء وحذف الغرف
- صوت WebRTC مع بدء اتصال للأعضاء الموجودين والجدد
- تصميم موبايل
- إعداد Render مبدئي

تشغيل:
npm install
npm start

مهم قبل الاستخدام العام:
- النشر يجب أن يكون HTTPS/WSS.
- استخدم قاعدة بيانات حقيقية بدل data.json.
- أضف TURN للصوت حتى يعمل عبر الشبكات الصعبة.
- أضف rate limiting وsession/JWT آمن وحماية CSRF/CORS حسب طريقة النشر.
- هذه حزمة مشروع وليست رابط استضافة جاهزًا.
